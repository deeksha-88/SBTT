# Python Training

My notes and practice code from the Python training. Each day has its own folder with a notes file (`.docx`) and the programs we did that day, one program per `.py` file.

## Folders

```
Python_Training/
├── Day_01/   basics, operators, loops, simple logic programs
├── Day_02/   lists, list methods, OOPs
├── Day_03/   arrays, patterns, polymorphism
└── Day_04/   polymorphism, enumerate, array problems
```

## What's in each day

**Day 1**
- Python basics, datatypes, operators (left shift, right shift)
- if / elif / else, break, continue, loops
- Even and odd numbers, prime number, all primes in one line
- Leap year, seconds to hours : minutes : seconds
- Codeforces 1475A (Odd Divisor)

**Day 2**
- Reversing an integer
- Lists and list methods
- Sum, alternate elements and reverse of a list
- OOPs basics, `__init__`, `self`, Student class

**Day 3**
- Contains duplicate, anagram
- Patterns: square, right angle, hollow square, pyramid
- Method overloading using `*args`, 2Sum

**Day 4**
- Polymorphism, method overloading
- `enumerate()`
- Dutch National Flag (Sort Colors), Move Zeroes, Two Sum

## How to run

You need Python 3 installed. Open the folder in a terminal and run any file like this:

```
python Day_01/prime.py
```

Some programs ask for input (like `prime.py` or `leap_year.py`), so just type the value and press Enter. For a list, type it with commas, like `1,2,3,4`.

The LeetCode ones (`sort_colors.py`, `move_zeroes.py`, `two_sum.py`) have a small test at the bottom, so they print the answer when you run them.

## Notes

The `.docx` file in each folder has the rough points and logic for that day. The code files are the same programs, so you can run them directly.
